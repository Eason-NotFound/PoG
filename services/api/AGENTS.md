# API/database account convention

Read `docs/api/ACCOUNT_PREFERENCES.md` before changing API demo users, login examples,
seed/provisioning, or authorization tests. The standard application usernames are
`foundation`, `recipient`, `donor`, and `admin`; `admin` remains only the internal
`human_approver` role with its independent manifest wallet. Do not infer owner,
Foundation, Recipient, payment, or arbitrary wallet authority from that username.
